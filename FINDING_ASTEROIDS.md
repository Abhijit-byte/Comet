## ⚠️ Troubleshooting

**Q: Why isn't asteroid X in live feed?**
→ Use Search tab - live feed only shows this week's approaches

**Q: Asteroid not found in search?**
→ Try different name (e.g., "(433) Eros" or "Eros")

**Q: No search results?**
→ Check spelling, try partial name

**Q: Want to go back to live feed?**
→ Click "Back to Live Feed" button after search
